minimaDocs Image Studio — release 0.1.2
2026-10-10

User scope
Fix the large-image stack overflow and inability to close/quit, then upgrade the
image workspace towards Photoshop. Reuse the user's Filtr project. Include a mix
of layers/selections/masks, colour and retouching, brushes/text/effects. Build a
properly Developer ID signed and Apple notarized Mac installer for user testing.
Existing Parlons integration changes and both host projects remain preserved.

Implementation
- Desktop strict base64 validation no longer uses a repeated-group regex.
- Save failures clear pending operations, pause autosave until explicit retry,
  and retain the saved document. Approved native close bypasses beforeunload.
- Dark image workspace, layer blend/opacity, undo/history, retouch shortcuts.
- Filtr live preview, 15 effects, 14 presets, colour grade and post-processing.
  Apply inserts a full-resolution image layer and hides the retained original.
- Editable alpha masks in layer.params.minimaMask; selection, hide/reveal brush,
  soft edges, inversion, enable/disable and remove. Raw layer pixels stay intact.
- Save/export flush current mask strokes, outstanding actions and image decoding.
- miniPaint's existing memory image store is enabled when IndexedDB is absent;
  pixel-edit undo/redo now restores exact source bytes without persistent caches.

Build
Run node scripts/prepare-image.cjs at repository root to build the pinned engine
with scripts/image-entry.js and image-source-loader.cjs. This leaves the sibling
image-engine source unchanged. Full prepare-editors.cjs invokes the same build.
Desktop version, lockfile and backend package-input jar are aligned at 0.1.2.
Use desktop/npm run dist:mac:signed, existing minimadesk Keychain profile, and
verify both the outer DMG and the app mounted from that exact disk image.

Product limits
16 MiB project/sharing cap remains. No PSD support. Applied effects are raster
copies, not Photoshop smart objects or continuously editable adjustment layers.
Masks use a minimaDocs layer parameter extension; plain older miniPaint ignores
it. This is a substantial image editor upgrade, not full Photoshop feature parity.
