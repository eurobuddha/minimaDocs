minimaDocs Android 0.3.3 / versionCode 303 — Image Studio parity

Shares workbench/image-studio.js, Filtr engine/control schema and the pinned
miniPaint engine with desktop. No separate reduced Android image editor.

Reused sources inspected:
- minimaDocs/android/app/src/main/assets/workbench/image-studio.js and bridge.js
- minimaDocs/desktop/tests/image-studio.test.cjs and image-save.test.cjs
- statenft-suite/minidapp/filtr-sheet.js, filtr-tabs.js, styles.css and Filtr tests
- image-engine/src/js/core/base-tools.js and tools/clone.js

Phone controls use Atelier's move/restore sheet lifecycle. Existing layer,
mask, colour, retouch, drawing/text and history controls remain the real engine
controls. Panels collapse for drawing and restore when a foldable/window widens.
Short landscape viewports place controls beside the canvas. Presets remain
reachable in the effects dialog. Mask strokes use pointer events (finger,
stylus, mouse) and block underlying legacy image tool gestures.

Imported image bytes now remain in a data URL. Revoking a blob URL broke Android
retouch undo decoding; the existing FileReader/miniPaint import path is reused.
Native Save remains visible alongside Export/File, removing duplicate action rows.

Validation:
- Release unit tests, lint and signed release build.
- Shared bridge: 11 regression checks; source Filtr regression suite.
- Android emulator API 36.1: actual touchscreen mask and brush strokes;
  selection mask/invert; exact pixel retouch undo/redo; blend/opacity;
  all 15 GPU effects and 14 presets; layered save/reopen with exact image data
  and structural layer-property equality; PNG dimensions; native host controls.
- Phone 360dp portrait and 800dp landscape, plus default 411dp emulator.
- Desktop image crash/save recovery, mask/effects, and cross-host project tests.
- Android fixture opens on Mac with exact layers and image data; controls relocate
  and restore at 360, 420, 768, 1024 and 1320px widths.
- The existing CI Android device workflow now runs Image Studio parity checks.

Synthetic screenshots/artifacts are in android/build; committed desktop fixture
was generated by the Android instrumentation test, not from a user document.

Existing limits: 16 MiB project/sharing cap, no PSD import/export, applied effects
are raster copies preserving the source layer. This is parity with minimaDocs
Image Studio on desktop, not a claim to implement every Adobe Photoshop feature.

Publication verification is appended after release.
